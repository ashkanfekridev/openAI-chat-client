# گپ — کلاینت چت OpenAI

یک رابط چت فارسی و راست‌چین برای OpenAI که با Laravel و Tailwind CSS ساخته شده است. گپ از Responses API استفاده می‌کند و گفتگوها، پیام‌ها و فایل‌های هر کاربر را در خود برنامه نگه می‌دارد.

## امکانات

- چت پیوسته با حفظ زمینه گفتگو از طریق `previous_response_id`
- ثبت‌نام، ورود، بازیابی رمز عبور و تأیید ایمیل
- جستجو، پوشه‌بندی، تغییر نام، سنجاق، آرشیو و حذف گفتگوها
- اشتراک عمومی و خروجی JSON، Markdown و چاپ/PDF
- پنل ادمین برای نمودار مصرف، هزینه تقریبی، نقش، وضعیت حساب، مدل‌های مجاز و سهمیه روزانه/ماهانه
- ثبت توکن‌های ورودی، خروجی و مجموع مصرف هر کاربر
- انتخاب مدل از داخل پنل کاربر
- آپلود هم‌زمان حداکثر ۵ فایل یا تصویر
- مشاهده تصاویر و دانلود فایل‌های پیوست‌شده
- ساخت تصویر با ابزار Image Generation در OpenAI
- System Prompt، Temperature و سطح Reasoning مستقل برای هر گفتگو
- جستجوی وب با نمایش منابع و citationهای قابل کلیک
- کتابخانه اسناد و RAG با OpenAI File Search و Vector Store
- ضبط صوت، تبدیل گفتار به متن و خواندن پاسخ با امکانات مرورگر
- توقف درخواست، کپی پاسخ و ویرایش/ارسال دوباره پیام
- نمایش امن پاسخ‌های Markdown به‌صورت HTML
- پشتیبانی از تیتر، فهرست، جدول، نقل‌قول، لینک و بلوک کد در پاسخ‌ها
- حالت روشن و تاریک با ذخیره انتخاب کاربر
- رابط واکنش‌گرا برای موبایل و دسکتاپ
- پیام‌های خطای فارسی و محدودسازی نرخ درخواست‌ها

## نکته درباره تاریخچه

OpenAI API فهرستی از تمام گفتگوهای انجام‌شده با یک API Key در اختیار این برنامه قرار نمی‌دهد. به همین دلیل گپ فقط گفتگوهایی را نمایش می‌دهد که از طریق همین برنامه ایجاد و در دیتابیس آن ذخیره شده‌اند.

گفتگوهای جدید به حساب کاربری احراز هویت‌شده متصل می‌شوند. هنگام اولین ورود، گفتگوهای قدیمی همان مرورگر که قبلاً با کوکی `chat_owner_token` ساخته شده‌اند نیز به حساب کاربر منتقل می‌شوند.

## نصب و راه‌اندازی

ابتدا وابستگی‌ها و فایل محیطی را آماده کنید:

```bash
composer install
cp .env.example .env
php artisan key:generate
npm install
```

کلید OpenAI را در فایل `.env` قرار دهید:

```dotenv
OPENAI_API_KEY=sk-your-api-key
OPENAI_MODEL=gpt-5.6-sol
OPENAI_TRANSCRIPTION_MODEL=gpt-4o-mini-transcribe
```

سپس دیتابیس و فایل‌های فرانت‌اند را آماده کنید:

```bash
php artisan migrate
npm run build
```

برای ساخت اولین مدیر، فرمان زیر را اجرا و رمز عبور را به‌صورت امن در prompt وارد کنید:

```bash
php artisan app:create-admin admin@example.com --name="مدیر"
```

برای اجرای محیط توسعه:

```bash
composer run dev
```

این فرمان سرور Laravel، پردازش صف، نمایش لاگ‌ها و Vite را هم‌زمان اجرا می‌کند. آدرس دقیق برنامه در خروجی `php artisan serve` نمایش داده می‌شود.

## تنظیمات OpenAI

تنظیمات اصلی در `config/services.php` قرار دارند:

| متغیر محیطی | مقدار پیش‌فرض | توضیح |
|---|---|---|
| `OPENAI_API_KEY` | ندارد | کلید محرمانه OpenAI؛ الزامی است |
| `OPENAI_MODEL` | `gpt-5.6-sol` | مدل پیش‌فرض انتخاب‌شده در رابط |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | آدرس پایه API |
| `OPENAI_TRANSCRIPTION_MODEL` | `gpt-4o-mini-transcribe` | مدل تبدیل گفتار به متن |

مدل‌های قابل انتخاب در آرایه `services.openai.models` تعریف شده‌اند. در نسخه فعلی این موارد در رابط نمایش داده می‌شوند:

- `gpt-5.6-sol` — بالاترین کیفیت
- `gpt-5.6-terra` — متعادل و سریع
- `gpt-5.6-luna` — سریع و اقتصادی

حالت ساخت تصویر در نسخه فعلی همیشه از `gpt-5.6-sol`، کیفیت `medium` و ابعاد `1024x1024` استفاده می‌کند.

اگر تنظیمات Laravel کش شده‌اند، پس از تغییر `.env` این فرمان را اجرا کنید:

```bash
php artisan config:clear
```

## فایل‌ها و تصاویر

فرمت‌های مجاز عبارت‌اند از:

- تصویر: `jpg`، `jpeg`، `png`، `webp` و `gif`
- سند و متن: `pdf`، `txt`، `md`، `json`، `html` و `xml`
- داده و آفیس: `csv`، `xls`، `xlsx`، `doc`، `docx`، `ppt` و `pptx`

در هر پیام حداکثر ۵ فایل و برای هر فایل حداکثر ۱۰ مگابایت مجاز است. فایل‌ها و تصاویر تولیدشده در دیسک خصوصی `local` و زیر مسیر `chat-attachments` ذخیره می‌شوند و فقط از route کنترل‌شده برنامه قابل دریافت هستند.

## نمایش Markdown

فقط پاسخ‌های دستیار به HTML تبدیل می‌شوند و پیام‌های کاربر به‌شکل متن ساده باقی می‌مانند. رندر پاسخ با ساخت مستقیم DOM انجام می‌شود؛ HTML خام مدل وارد صفحه نمی‌شود و لینک‌ها فقط با پروتکل‌های امن `http`، `https` و `mailto` فعال می‌شوند.

## احراز هویت و مدیریت مصرف

ثبت‌نام برای کاربران عادی از مسیر `/register` و ورود از مسیر `/login` انجام می‌شود. کاربران فقط گفتگوها و پیوست‌های متعلق به حساب خود را می‌بینند.

مدیر از مسیر `/admin/users` می‌تواند:

- تعداد کاربران، گفتگوها و مجموع مصرف را مشاهده کند.
- توکن‌های ورودی، خروجی و کل مصرف هر کاربر را ببیند.
- برای هر کاربر سقف توکن تعیین کند؛ مقدار خالی به معنی مصرف نامحدود است.
- شمارنده دوره فعلی کاربر را صفر کند.
- حساب را فعال یا غیرفعال و نقش کاربر را تعیین کند.
- مدل‌های مجاز و دوره سهمیه روزانه، ماهانه یا بدون دوره را تنظیم کند.
- نمودار مصرف ۱۴ روز اخیر و هزینه تقریبی را ببیند.

پس از رسیدن مصرف کل به سقف تعیین‌شده، ارسال درخواست جدید به OpenAI متوقف می‌شود. جزئیات تاریخی مصرف روی پیام‌های دستیار حفظ می‌شوند و صفرکردن مصرف فقط شمارنده دوره فعلی کاربر را پاک می‌کند.

## ساختار داده

- `users`: مشخصات ورود، نقش ادمین، سقف و شمارنده‌های مصرف
- `conversations`: حساب مالک، عنوان، مدل انتخاب‌شده و آخرین شناسه پاسخ OpenAI
- `conversation_folders`: پوشه‌های شخصی تاریخچه
- `knowledge_documents`: اسناد متصل به Vector Store هر کاربر
- `chat_messages`: نقش پیام، متن، پیوست، citation، هزینه تقریبی و جزئیات توکن
- فایل‌ها: ذخیره در `storage/app/private/chat-attachments`

برای ادامه یک گفتگو، آخرین `openai_response_id` ذخیره و در درخواست بعدی به‌عنوان `previous_response_id` ارسال می‌شود.

## مسیرهای برنامه

| متد | مسیر | کاربرد | محدودیت نرخ |
|---|---|---|---|
| `GET` | `/` | نمایش رابط و تاریخچه گفتگوها | — |
| `GET/POST` | `/login` | نمایش و پردازش ورود | ۵ درخواست POST در دقیقه |
| `GET/POST` | `/register` | نمایش و پردازش ثبت‌نام | ۵ درخواست POST در دقیقه |
| `POST` | `/logout` | خروج از حساب | — |
| `POST` | `/chat` | ارسال پیام، فایل یا درخواست ساخت تصویر | ۱۰ درخواست در دقیقه |
| `POST` | `/speech/transcribe` | تبدیل صوت به متن | ۱۰ درخواست در دقیقه |
| `POST/DELETE` | `/knowledge-documents` | مدیریت کتابخانه اسناد | فقط مالک |
| `PATCH/DELETE` | `/conversations/{conversation}` | تنظیمات یا حذف گفتگو | فقط مالک |
| `POST` | `/conversations/{conversation}/pin` | سنجاق‌کردن گفتگو | فقط مالک |
| `POST` | `/conversations/{conversation}/archive` | آرشیو یا بازگردانی | فقط مالک |
| `GET` | `/shared/{shareToken}` | مشاهده نسخه عمومی گفتگو | عمومی |
| `GET` | `/conversations/{conversation}` | دریافت پیام‌های یک گفتگو | ۶۰ درخواست در دقیقه |
| `GET` | `/conversations/{conversation}/messages/{chatMessage}/attachments/{attachment}` | مشاهده یا دانلود پیوست | ۱۲۰ درخواست در دقیقه |
| `GET` | `/admin/users` | پنل مدیریت کاربران و مصرف | فقط ادمین |
| `PUT` | `/admin/users/{user}/usage-limit` | تغییر سقف مصرف | فقط ادمین |
| `POST` | `/admin/users/{user}/usage-reset` | صفرکردن مصرف دوره فعلی | فقط ادمین |

دسترسی به گفتگو و پیوست بر اساس حساب احراز هویت‌شده بررسی می‌شود و منابع متعلق به کاربران دیگر با پاسخ 404 مخفی می‌شوند.

## امنیت و استقرار

- هرگز فایل `.env` یا مقدار `OPENAI_API_KEY` را commit نکنید.
- کلید API فقط در سرور استفاده می‌شود و به JavaScript مرورگر ارسال نمی‌شود.
- در محیط production مقدار `APP_DEBUG=false` و یک `APP_URL` صحیح تنظیم کنید.
- سیاست نگهداری و حذف دوره‌ای گفتگوها و فایل‌ها را متناسب با نیاز خود اضافه کنید.
