راه‌اندازی توسعه

composer install
cp .env.example .env
php artisan key:generate
npm install
php artisan migrate
npm run build
composer run dev

composer run dev سرور Laravel، queue worker، Pail و Vite را با هم اجرا می‌کند. عملیات OpenAI فعلاً داخل همان درخواست HTTP است و به queue ارسال نمی‌شود.

در خطای OpenAI پیام و گفتگو ذخیره نمی‌شوند. exception با report() ثبت می‌شود و body خام سرویس خارجی به کاربر نمایش داده نمی‌شود.

Docker و Production

compose.yaml برای SQLite و storage از volume استفاده می‌کند، پورت‌های ۸۰ و ۴۴۳ را منتشر می‌سازد و مسیر /up را health check می‌کند. entrypoint وجود APP_KEY و OPENAI_API_KEY را بررسی، مسیرها را آماده، برنامه را optimize و migrationها را اجرا می‌کند.

محدودیت فعلی: Compose از build target با نام runtime استفاده می‌کند، اما Dockerfile فعلی چنین stageای ندارد و Caddyfile را هم وارد image نمی‌کند. پیش از deployment باید Dockerfile و Compose هماهنگ شوند.

چک‌لیست نگهداری

  • مدل‌ها و قیمت‌ها را فقط در config/services.php تغییر دهید و config cache را پاک کنید.
  • دیتابیس و storage/app/private را با هم backup بگیرید.
  • timeout وب‌سرور و proxy را با timeout صدوهشتاد ثانیه‌ای OpenAI هماهنگ کنید.
  • برای cleanup درست، فایل و گفتگو را از endpoint برنامه حذف کنید، نه مستقیماً از دیتابیس.
  • کارهای طولانی و قابل retry مانند پردازش حجیم سند را در آینده به Job و queue منتقل کنید.
  • در production از APP_DEBUG=false، cookie امن و secret store مناسب استفاده کنید.
