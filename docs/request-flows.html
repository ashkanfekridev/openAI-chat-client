۵. رندر پاسخ
  1. JavaScript پیام را خوش‌بینانه نمایش می‌دهد و متن، مدل، حالت، شناسه گفتگو و فایل‌ها را با FormData به POST /chat می‌فرستد.
  2. SendChatMessageRequest ورودی را اعتبارسنجی می‌کند. سپس حساب فعال، دوره سهمیه، مدل مجاز و مالکیت گفتگو بررسی می‌شوند.
  3. OpenAIClient::respond() payload را می‌سازد. برای ادامه گفتگو، previous_response_id از آخرین پاسخ ذخیره‌شده ارسال می‌شود.
  4. پس از موفقیت OpenAI، transaction گفتگو را در صورت نیاز می‌سازد، دو پیام را ثبت، شناسه پاسخ را update و مصرف کاربر را increment می‌کند.
  5. JSON امن شامل گفتگو، پیام‌ها و مصرف جدید به مرورگر می‌رسد و history و UI به‌روزرسانی می‌شوند.
OpenAI streaming واقعی وجود ندارد. سرور پاسخ کامل را می‌گیرد و JavaScript متن نهایی را به شکل تدریجی در DOM نمایش می‌دهد. Abort مرورگر الزاماً پردازش upstream را متوقف نمی‌کند.

فایل و تصویر

چت معمولی

در هر پیام حداکثر پنج فایل پذیرفته می‌شود. تصویر به صورت input_image و سایر فایل‌ها به صورت input_file با data URL ارسال می‌شوند. برای PDF مقدار detail روی low است.

تولید تصویر

حالت تصویر از gpt-5.6-sol، کیفیت medium و اندازه 1024x1024 استفاده می‌کند. خروجی base64 به PNG خصوصی تبدیل و به عنوان پیوست پیام دستیار ذخیره می‌شود.

جستجوی وب

annotationهای url_citation معتبر استخراج، بر اساس URL یکتا و همراه پیام ذخیره می‌شوند.

file_search
  1. سند ابتدا در فضای خصوصی کاربر و با status برابر processing ثبت می‌شود.
  2. فایل در OpenAI Files آپلود می‌شود.
  3. اگر کاربر Vector Store ندارد، یک مورد ساخته و شناسه آن روی User ذخیره می‌شود.
  4. فایل به Vector Store متصل و سند ready می‌شود.
  5. وقتی use_knowledge گفتگو فعال باشد، پاسخ بعدی ابزار file search را دریافت می‌کند.

خطای آپلود خارجی باعث حفظ رکورد با status برابر failed و یک پیام امن می‌شود.

گفتار

MediaRecorder صدای مرورگر را به POST /speech/transcribe می‌فرستد و متن برگشتی داخل textarea قرار می‌گیرد. خواندن پاسخ با speechSynthesis خود مرورگر انجام می‌شود.

مدیریت گفتگو

endpointهای جدا برای update تنظیمات، pin، archive، share، unshare، delete و export وجود دارند. export در قالب JSON، Markdown یا صفحه چاپ انجام می‌شود. لینک عمومی با token تصادفی ۴۸ کاراکتری ساخته می‌شود و صفحه مقصد فقط‌خواندنی است.
